# Local controller assets

Selected unmodified assets from `@webxr-input-profiles/assets@1.0.20`, MIT licensed (see LICENSE.md). Source: https://github.com/immersive-web/webxr-input-profiles. Npm tarball SHA-1: `54b31d7b58f36216e3f246a139def54e7dd572a3`.

Only the generic-trigger and Meta/Oculus Touch profiles listed in profilesList.json are bundled. XRControllerModelFactory uses this same-origin directory instead of its default CDN. Unknown devices retain controller rays, trigger-activated in-world controls, and a generic/procedural visual fallback; unsupported optional shortcuts are not guessed.
